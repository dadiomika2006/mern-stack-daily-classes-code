Components In React:
--------------------
      ->Components are the smallest UI blocks called as Components

 Types:
 ---------
 1. Class based Components
    ->Components are declared using class keyword is called as class based Components
    ->In CBC constructors,super keyword, this keyword is present also render(), and life cycle methods are present
    ->In CBC state are present so that's why is called as a statefull components

    syntax:
            import (component) from "react";
            class classname extends components{
                render(){
                    return(
                        hrml code;
                    )
                }
            }
            export default classname;

 2.FUnction based components: (16.8 ->hooks)
    -> we can declare FBC using arrow function or normal function or functional expression
    ->In FBC constructors,super keyword,this keyword are not present.
    ->render() and lifecycle  methods alsp not present.
    ->IN FBC states are nots present so thst's why this is also called as stateless components.

    syntax1:

            const ComponentName()=>{
                return{
                    html code
                }
            }
            export default ComponentName;
    syntax2:

            function ComponentName(){
                return{
                    html code
                }
            }
            export default ComponentName();
    syntax3:

            const ComponentName=function(){
                return{
                    html code..
                }
            }
            export default ComponentName;
