JSX(Javascript and xml[extendable markup language]):
----------------------------------------------------
->react will understand JSX code but browsers will not understand JSX code,it understands only js code (because every browser having Js engine)
->to convert JSX code to js we have next generation compiler called "babel JS"

-> JSX is similar to HTML , here it allows both JS and HTML code

Rules:
-------
        jsx files always starts with captial letters
        here we can achieve js expression
        In return function html elements contains parentTag
        jsx will allow empty(<> </>)

Components:
-----------
    -> they are the smalllest UI blocks 
    called as a Components type, they are:

    types:
    ------
    1.Class based component(CBC): 
    ----------------------------
        ->components are declared using class keyword
        ->In CBC constructors ,super keywords,this keywords is present also render(),and life cycle method are present
        ->In CBC states are present so, it is called STATED COMPONENTS
         Syntax:
            import {Component} from 'react';
            class Classname extends Components{
                render(){
                return(
                    html code
                    )
                }
            }

            export default Component;

    2.Function based component(FBC):
    --------------------------------
        ->we can FBC using arrow functions or normal functions or functional expression
        ->in FBC constructors,  keyword, this keyword not present
        ->in fbc states are not present which is why it is called STATELESS COMPONENTS
        Sntax
            1.const ComponentName=()=>{-------------> using arrow function
                return(
                    html code here....
                )
            }
            export default ComponentName;

            2.function ComponentName(){
                return(
                    html code here------------------->normal function
                )

            }
